# Source notice

This repository is an unofficial reconstruction of the MKS SERVO42C V1.1.3 firmware for the HC32L130. It is not the original Makerbase source release and is not affiliated with or endorsed by the manufacturer. Original source names, comments, compiler settings and organization are not known.

The C implementation and the exact assembly reference are separate representations. The C build is independently compilable but not byte-identical to the factory executable. The assembly build reproduces the original application prefix. Neither build has been tested on physical hardware in this project.

Redistribution rights for the vendor-derived code, assembly, graphics, tables and recovered test data have not been established. No license for these materials is asserted. Keep the repository private until applicable distribution permissions are confirmed.

Do not commit full flash backups, generated board images, identity data or calibration data.
