# Source notice

This is an unofficial C reconstruction of the MKS SERVO42C V1.1.3 firmware for the HC32L130, based on a captured binary. It is not a Makerbase source release. Names, comments and source organization are reconstructed; the original compiler and build options are unknown.

The application is independently buildable, but its compiled instructions are not byte-identical to the vendor executable. Host tests do not establish hardware operation, exact interrupt timing, or recovery after loss of power during flash writes. Distribution rights for vendor-derived code and assets have not been established. No vendor license or endorsement is implied.
